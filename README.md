# Public

This repository hosts personal projects and experiments.

## What You Will Find

- Independent project folders, each focused on a specific idea or build.
- Project-level documentation inside each folder (usually a local README).
- Source files, scripts, and generated artifacts that belong to each project.

## How To Use This Repository

- Browse folders at the repository root to find a project of interest.
- Open that project's README for setup steps, usage, and notes.
- Run commands from the repository root unless a project README says otherwise.

## Conventions

- Projects are self-contained in their own directories.
- Dependencies and tooling can vary by project.
- Generated files may be committed when they are useful outputs of a project.

## Status

This is an active personal workspace, so projects may be added, reorganized, or updated over time.
